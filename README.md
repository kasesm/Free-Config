### 📝 How to Use

1. Copy the subscription link you need
2. Paste it into your VPN client's subscription URL field
3. Update/refresh the subscription
4. Connect to your preferred server

### نحوه استفاده

۱. لینک اشتراک مورد نظر را کپی کنید
۲. آن را در قسمت URL اشتراک کلاینت VPN خود قرار دهید
۳. اشتراک را به‌روزرسانی کنید
