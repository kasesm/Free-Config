# 🚀 Free Config | کانفیگ رایگان

این پروژه شامل مجموعه‌ای از کانفیگ‌های رایگان و بروزرسانی‌شده برای پروتکل‌های مختلف است. برای مشاهده جزئیات و دریافت لینک‌ها، بخش زبان مورد نظر خود را باز کنید.

## 📝 توضیحات
این کانفیگ‌ها از کانال‌های تلگرامی جمع‌آوری می‌شوند، تا حدی تست شده و در ساب‌لینک‌های مربوطه قرار می‌گیرند. در وب‌سایت ما همیشه اطلاعات درباره بروزرسانی کانفیگ‌ها وجود دارد و می‌توانید کانفیگ‌ها را مستقیماً از آنجا نیز کپی کنید.

## 🔗 ساب‌لینک‌های مستقیم
لینک‌های زیر را کپی کرده و در برنامه مورد نظر خود وارد کنید. دکمه کپی در گوشه سمت راست هر باکس قرار دارد.
